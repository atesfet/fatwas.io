# FatWAS Interactive Website

Interactive results for the FatWAS manuscript:

**Phenome-wide associations of CT-derived adipose area and density in 22,710 patients: uncovering unexpected disease connections**

Live site: https://atesfet.github.io/fatwas.io/

Results version: v18 (corrected full-cohort PheWAS; 624 phenotypes, 2,496 marker–phenotype tests,
922 Bonferroni-significant associations; joint area–density atlas).

## Contents

- `index.html`: landing page with the abstract, study summary, per-marker plots, the association table, the joint area–density atlas and downloads
- `plot.html`: Manhattan/volcano plot of all 624 tests for one marker (`?metric=SFI&type=manhattan`)
- `overall.html`: top 120 significant associations across the four markers
- `data/all_associations.csv`: all 2,496 single-marker tests (`significant` = p < 0.05/2,496)
- `data/significant_associations.csv`: the 922 significant associations (also at the root as `significant_associations.csv` for older links)
- `data/joint_atlas.csv`: the 500 phenotypes with a joint signal (Tiers 1–3), as shown in the atlas table
- `data/joint_atlas_full.csv`: the full atlas for all 624 phenotypes
- `data/site_numbers.json`: every number quoted on the page, computed from the data
- `static/`: CSS/JS/font assets

The `data/` files are generated by `src/19_build_website_data.py` in the v18 analysis directory
from `phewas_full_cohort/sup_table_1_results_*.csv` and `atlas/FatWAS_joint_area_density_atlas.csv`.
Odds ratios are per one standard deviation of the sex-specific z-scored marker.

## Local preview

From this directory:

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`

## Deployment

GitHub Pages serves the `main` branch root. Pushing to `main` updates the site.
